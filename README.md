# Carv3D

**English** · [Deutsch](README.de.md)

**Carv3D is a direct CAD modeler for 3D printing and maker projects.**

The goal is a focused modeling environment for people who want to create precise parts without first learning a large industrial CAD suite. Carv3D works with true solid bodies and supports common 3D exchange formats.

## Current status

Carv3D is in an early **0.1 beta**. This phase focuses on practical testing, clear interaction, and reliable project saving, loading and export.

- The beta is free.
- Beta builds are time limited; the current plan allows modeling through **31 March 2027**.
- The application core is proprietary and will remain closed source.
- There is no subscription or mandatory account.
- Projects are processed locally.
- Purchasing and licensing are planned for a stable version 1.0.

The test version is currently distributed only to invited participants. There is no public beta download.

### Apply for the private beta

Tell us briefly what you would like to build with Carv3D:

- [Apply on the Carv3D website](https://carv3d.de/Beta.html#beta)
- Email: [beta@carv3d.de](mailto:beta@carv3d.de)

Applications are reviewed in small waves. Applying does not automatically grant access; selected testers receive a personal invitation by email.

After a beta build expires, existing projects remain openable, saveable and exportable as STEP, STL or 3MF. Editing continues with a current beta or a licensed release.

## Pricing direction

The current target for version 1.0 is a perpetual license at about **€49**, free educational use for verified teachers, and a **€10–15** perpetual education license for students. There is no subscription or mandatory account planned. These are planning targets and will be finalized before sales begin.

See [Pricing principles](PRICING.md) for the full proposal.

## What Carv3D is for

- technical parts for 3D printing
- direct modeling with faces, edges and solid bodies
- holes, screws, nuts, inserts and magnets
- print checks, material estimates and orientation guidance
- STL, 3MF and STEP export

The extension system is still under development. A public directory will open only after review, package approval and technical hardening are ready. Official community extensions are intended to have visible source code, pass review before inclusion and remain free of charge.
