# Community extensions

Source of community extensions for Carv3D. Each folder is one extension with its **own license** (see the `LICENSE` file inside the folder); the license of the repository root does not apply to it.

Extensions that start programs or read files into the document are checked by the Carv3D team before Carv3D accepts them. How to write an extension: the Carv3D SDK (`@carv3d/sdk`).

| Extension | What it does | License |
|---|---|---|
| [mesh-mix-s2c](mesh-mix-s2c/) | Converts a mesh body to exact faces with the separately installed program [Mesh Mix-S2C](https://github.com/STL2CURVES-MMM/Mesh-Mix-S2C) | AGPL-3.0-only |
