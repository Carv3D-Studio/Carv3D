# Beta testing guide

**English** · [Deutsch](BETA_TESTING.de.md)

Carv3D 0.1 is an early test version. Keep an additional copy of important work in an exchange format such as STEP or 3MF.

## Free 30-day test

The beta is free for **30 days from your first start**, with the full range of functions including saving and export. Access is issued in small waves after an [application](https://carv3d.de/Beta.html#beta). On request we can extend the period. Personally invited early testers can model through **31 March 2027**.

When your test period ends, this build continues to open and save projects and export STEP, STL and 3MF files. Editing continues after an extension, with a current beta or with a licensed release. The program shows the remaining days in **Help → About Carv3D …** and warns you in the last seven days.

## Early supporter reward

Planning goal, not a binding promise: we intend to give a free lifetime license for version 1.0 to up to 10 early testers who actively report confirmed, reproducible bugs. What counts as "active" and "confirmed" is decided by Carv3D; there is no legal entitlement, and the terms may change before 1.0.

## Particularly useful tests

1. Model a small real part from start to finish.
2. Save the project, restart the application and load the project again.
3. Export the model as STEP and as 3MF or STL.
4. Open the export in a slicer or another CAD application.
5. Report unclear steps, errors and unexpected results.

## Good bug reports

A good report describes the shortest path that reproduces the problem. Include the version, operating system and browser. Attach project files only when they contain no confidential information.

## Privacy

Carv3D does not automatically send project files or error reports. When attaching a file to a report, you decide which information becomes public.
