# Carv3D Public Repository Guide

This repository is the public information and feedback hub for Carv3D.

## Scope

- Keep the Carv3D application source, internal architecture documents, credentials, signing keys and unpublished builds out of this repository.
- Public content belongs in `README.md`, `ROADMAP.md`, `docs/` and `.github/`.
- Product behavior must be described as it exists. Planned work must be labelled as planned.
- Do not publish personal tester data, private reports or project files without explicit permission.
- Security reports belong in the private reporting channel described in `SECURITY.md`, not in public issues.

## Changes

- Use short, clear German text; add English documentation only when it is maintained at the same quality.
- Check links and headings before committing.
- Keep one subject per commit and update the visible roadmap or changelog when users are affected.
